# Particle Life Simulator

EIn Partikle-Life-Simulator ist ein klassisches Beispiel von Emergenz: Viele einfache Partikel folgen eigenen simplen Anziehungs- und Abstoßregeln und erzeugen so komplexe Muster. 

In diesem Projekt erstellen wir in einer 3er Gruppe einen solchen Simulator.

[Screenshot]


## Installation

1. Projekt klonen mit
```bash
git clone https://github.com/git-nny/emergent-bees.git
```
2. notwendige Packages installieren mit
```bash
uv sync
```

## Anwendung starten

Anwendung über das Terminal starten:
```bash
python [name]
```
